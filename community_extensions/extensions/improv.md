  extended_description: |
    Improv is a multidimensional spreadsheet in the Lotus Improv / Quantrix
    tradition: data lives in categories (Time, Product, Region) instead of
    cell addresses, and formulas name measures (`Revenue = Price *
    Quantity`), so one formula covers every cell it applies to.

    This extension brings its formula engine to DuckDB:

    - `improv_calc(formula [, inputs])` evaluates a scalar Improv formula
      (math, statistics, financial, text, dates, engineering, `IF`, `LET`,
      `LAMBDA`; aggregations over categories need a model) on named inputs
      passed as a JSON object. An error value is NULL; `improv_calc_text`
      returns any type and renders errors (`#DIV/0!`).
    - `improv_functions([query := ...])` lists the functions with their
      signatures and descriptions.
    - `improv(source, model)` reads a table or a SELECT, builds a model from
      a short spec (categories from columns, inputs from columns with an
      optional sum/avg/min/max/count, derived measures as formulas, with
      aggregations across categories and PREV/NEXT along them) and returns
      one row per computed cell, ready to join.

    The same engine runs Improv's desktop GUI, terminal UI, CLI and its
    PostgreSQL extension (pg_improv). Source: https://codeberg.org/gregburd/improv
