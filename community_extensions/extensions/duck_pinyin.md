    Native Chinese pinyin conversion and ordered phrase matching, ported from
    pg_pinyin with pinned embedded dictionaries. Includes character conversion,
    longest-phrase polyphonic disambiguation, batch documents, pre-tokenized
    input, and explicit per-call dictionary overrides.

    Query modes include full syllables, initials, autocomplete, automatic, and
    legacy compatibility parsing. Ordered matching supports a total skipped-token
    budget. The core extension is independent of PostgreSQL and FTS.

    An optional official FTS/BM25 SQL example is provided separately. Its current
    dynamic-term macro has a documented correlated-query scaling limitation;
    consult the repository benchmarks before using that example on large tables.

    Extension code is MIT licensed. Embedded phrase dictionary data includes
    CC-BY-SA-4.0 material. Source attribution, pinned data manifests, and complete
    data license texts are included in the repository and release archives.
