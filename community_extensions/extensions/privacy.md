    Everything is reachable through one dispatcher that mirrors the source API, plus single-argument convenience scalars:

    ```sql
    SELECT privacy('{"op":"mask_cn","v":"110101199003071234","kind":"idcard","mode":"birth"}');
    SELECT privacy('{"op":"fpe_encode","v":"1234567890","key":"00000000000000000000000000000000","algo":"ff31"}');
    ```

    **Verified**: 24 unit tests; FPE checked differentially against an independent Python oracle (15 NIST FF3 + 18 FF3-1 vectors, encrypt + decrypt).
