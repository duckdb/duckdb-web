    ## bson — BSON / Extended-JSON v2 in SQL

    Decode a BSON document to MongoDB's Extended JSON, build one back,
    validate it (with a classified error taxonomy), project any dotted
    path with a type coercion, and read/write ObjectIds — all in SQL,
    right where you query.

    Built as a DuckDB loadable extension with the
    [quack-rs](https://crates.io/crates/quack-rs) C-API binding layer.
    The engine (`bson_core/`) is a verbatim port of the
    [Query-farm `vgi-bson`](https://github.com/Query-farm/vgi-bson)
    bson-core crate (MIT) — a pure-Rust structural decoder over the
    official `bson` crate, with no Arrow, no VGI, and no `mongodb`
    driver; only the transport layer was replaced with direct C-API
    vector I/O.

    **9 Functions:**

    | Function | Signature | Returns |
    |----------|-----------|---------|
    | `bson_to_json` | `(doc BLOB, mode VARCHAR)` | `VARCHAR` — Extended-JSON v2 (`canonical` / `relaxed`) |
    | `bson_decode` | `(doc BLOB)` | `VARCHAR` — Extended-JSON v2 canonical |
    | `bson_from_json` | `(json VARCHAR)` | `BLOB` — Extended-JSON v2 -> BSON bytes |
    | `bson_is_valid` | `(doc BLOB)` | `BOOLEAN` — single well-formed BSON document |
    | `bson_well_formed` | `(doc BLOB)` | `STRUCT(ok, error, kind)` — classified failure taxonomy |
    | `bson_field` | `(doc BLOB, path VARCHAR, mode VARCHAR)` | `VARCHAR` — leaf at dotted path, coerced (inference / `objectid` / `decimal` / `uuid` / `timestamp` / `datetime` / `blob` / `json`) |
    | `bson_type_of` | `(doc BLOB, path VARCHAR)` | `VARCHAR` — BSON type name at path (or top level) |
    | `bson_objectid_hex` | `(oid BLOB)` | `VARCHAR` — 12-byte ObjectId -> 24-char hex |
    | `bson_objectid_from_hex` | `(hex VARCHAR)` | `BLOB` — 24-char hex -> 12-byte ObjectId |

    The decoder is total and bounds nesting depth, so a hostile blob
    fails its own row, never crashes the scan. NULL flows through.
