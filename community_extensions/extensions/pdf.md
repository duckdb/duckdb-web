    **Everything PDF, in SQL** — Poppler, Tesseract (OCR), qpdf, and libharu,
    statically linked; Apple Vision on macOS. Paths or globs; no external tools
    at runtime for core ops. Full docs and recipes:
    [API reference](https://github.com/asubbarao/duckdb-pdf/blob/cde4d9d0291d934c3f3565ff75d4305ff9466505/README.md) and
    [cookbook](https://github.com/asubbarao/duckdb-pdf/blob/cde4d9d0291d934c3f3565ff75d4305ff9466505/COOKBOOK.md).

    **New in 0.10.0** — Apple Vision is a second OCR engine on macOS
    (`ocr_backend := 'vision'`, or `backend: 'vision'` on `ocr_image`), and
    `image_barcodes` reads barcodes and QR codes from images. The default
    `auto` layout keeps two-column pages split around full-width figures, and
    reads rotated text (such as arXiv's margin stamp) as its own lines instead
    of merging it into the text beside it.

    **API (0.9.0)** — 20 public names replace the earlier separate entry
    points; retired names are removed. See the
    [migration table](https://github.com/asubbarao/duckdb-pdf/blob/cde4d9d0291d934c3f3565ff75d4305ff9466505/README.md#migration-from-48-names).
    This source targets DuckDB 2.0.0.

    **Discover functions** — `duckdb_functions()` exposes parameter names,
    descriptions and examples. Scalar options use validated STRUCT fields.
    `pdf_render` and `ocr_image` each have scalar and table forms.

    **Read** — `read_pdf` selects page, line, element, table or chunk grain;
    `read_pdf_words` returns word boxes, geometric `line`, `column_index` and
    page size. Auto-OCR on image-only pages for page/line/word/table readers;
    element/chunk OCR is opt-in. English model bundled.

    **Inspect** — `pdf_info` selects metadata/permissions or qpdf statistics;
    `pdf_objects` selects pages, outline, tagged structure, destinations, fonts,
    attachments, form fields, annotations, revisions, signatures or images.

    **Convert / render** — `pdf_text` selects text, Markdown, HTML, XML or JSON;
    `pdf_render` renders PNG/SVG as a scalar or streams pages as a table.
    `ocr_image` has scalar and table forms, with text/hocr/tsv output.

    **Transform & write** — `pdf_merge`, `pdf_pages`, `pdf_split`, `pdf_stamp`,
    `pdf_rewrite`, `pdf_sign`, `pdf_redact`, `pdf_ocr`;
    `write_pdf` / `COPY … (FORMAT pdf)`;
    `to_pdf` for office docs (Microsoft or Apple apps on macOS, LibreOffice
    elsewhere).

    **Scope** — deterministic extraction, not ML document AI. **License** —
    GPL-2.0-or-later (Poppler).
