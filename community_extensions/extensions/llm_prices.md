  extended_description: |
    Prices LLM API usage inside DuckDB. The extension bundles the
    [llm-prices](https://crates.io/crates/llm-prices) table: one row per model for Anthropic,
    OpenAI, Google, DeepSeek, Mistral, xAI, Cohere, Groq, Together AI and Fireworks AI, each
    read from the provider's pricing page and dated. Prices are compiled in, so nothing is
    fetched at query time, no key is needed, and it works in DuckDB-Wasm.

    | Function | Returns |
    | --- | --- |
    | `llm_cost(model, input_tokens, output_tokens, cached_tokens := 0)` | USD cost of one request as `DOUBLE`, `NULL` for a model the table does not price |
    | `llm_model_id(model, provider := '')` | the table's model id for a raw id, for joins |
    | `llm_prices()` | one row per model: every price per 1M tokens, aliases, status, source URL and check date |
    | `llm_prices_version()` | the date the bundled table was checked |

    `input_tokens` are uncached input tokens (for OpenAI usage, `prompt_tokens` minus
    `prompt_tokens_details.cached_tokens`) and `cached_tokens` are prompt-cache reads.
    `llm_cost` also takes `cache_write_5m_tokens`, `cache_write_1h_tokens`, `batch := true`
    for Batch API prices, and `provider := 'groq'` to pick one provider's row. Long-context
    prices apply automatically above a model's threshold. Model ids match in any case and
    with provider prefixes (`anthropic/`, `openrouter/`), Bedrock and Vertex ids, dated
    snapshots and `-latest` aliases.

    It pairs with extensions that call models from SQL (`ai`, `open_prompt`, `llm`) and with
    usage exports from Langfuse, Helicone, gateways or OpenTelemetry `gen_ai` spans.
    New llm-prices releases ship as version bumps of this extension.
