    Geocode New York City addresses, borough-block-lot numbers, and building
    identification numbers using NYC Department of City Planning Geosupport.

    Requires DuckDB 1.5.6+ and Linux x86-64 (glibc). The adapter embeds its native
    worker; Python and Docker are not runtime requirements. NYC's engine and
    quarterly data have separate terms and are not included in the extension.
    Installing a bundle is explicit, uses pinned checksums, and needs several
    GiB of disk. No bundle is downloaded by INSTALL or LOAD of the extension.

    ```sql
    CALL gs_install('26c');
    SET VARIABLE geosupport_release = (SELECT bundle_id FROM gs_load('26c'));
    SELECT gs_address('125', 'Worth St', 'Mn');
    ```

    External filesystem access, HTTPS downloads, and native worker execution
    require enable_external_access=true. Native operations have timeouts but do
    not yet stop promptly when a DuckDB query is interrupted. See the source README and
    THIRD_PARTY_NOTICES.md for runtime requirements and licensing details.
