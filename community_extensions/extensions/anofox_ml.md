    CREATE TABLE train AS
      SELECT (i % 2)::DOUBLE AS y, [i::DOUBLE, (i % 2) * 3.0 + (i % 5) * 0.1] AS x
      FROM range(100) t(i);
    -- fit a model in an aggregate; it is an ordinary BLOB value
    CREATE TABLE models AS
      SELECT ml_fit_agg('RandomForestClassifier', y, x, '{"n_estimators": 50, "seed": 42}') AS model
      FROM train;
    SELECT ml_predict(model, [7.0, 3.2]) AS label,
           ml_predict_proba(model, [7.0, 3.2]) AS proba
    FROM models;

    anofox_ml brings the anofox-ml Rust library into SQL. `ml_fit_agg(kind, y, x [, params])` fits any of
