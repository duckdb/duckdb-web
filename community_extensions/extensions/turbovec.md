    ## turbovec — Compressed Vector Search for DuckDB

    High-performance approximate nearest neighbor (ANN) search using
    Google's TurboQuant data-oblivious product quantization, with IVF
    indexing, rerank, ensembles, and filtered search.

    **12 Functions:**

    | Function | Description |
    |----------|-------------|
    | `turboquant_build(str, dim, bits, path)` | Build index from nested-array string |
    | `turboquant_build_list(LIST, bits, path)` | Build from a flat vector LIST (dim auto) |
    | `turboquant_build_concat(path, dim, bits, str)` | Append CSV vectors to an index |
    | `turboquant_build_ivf(str, dim, bits, nlists, dir, [keep_raw])` | Build IVF index (nlists 0 = auto √n) |
    | `turboquant_build_ensemble(str, dim, bits, m, dir)` | Ensemble of m decorrelated indexes |
    | `turboquant_add(path, str, dim)` | Incremental add |
    | `turboquant_remove(path, idx)` | Incremental remove |
    | `turboquant_search(path, query, k)` | Top-k search (l2/cosine/dot) |
    | `turboquant_search_within(path, query, eps, k)` | Radius (WITHIN) / top-k+eps fused search |
    | `turboquant_search_ivf(dir, query, k, probes, [rerank_factor])` | IVF search, optional rerank |
    | `turboquant_search_ivf_filter(dir, query, k, ids, [max_probes:=], [rerank_factor:=])` | Filtered IVF search (pgvector-style iterative scan) |
    | `turboquant_search_ensemble(dir, query, k)` | Ensemble search (score-averaged) |
    | `turboquant_score(path, query)` | Full scoring, all vectors ranked |
    | `turbovec_config(knob, value)` | Set/get process-wide search defaults |

    **Features:**
    - **2-bit (16×) / 4-bit (8×)** data-oblivious compression, zero training
    - **SIMD** search: NEON (ARM), AVX-512BW/AVX2 (x86)
    - **Beats FAISS PQ**: +0.2–1.9pp R@1 on OpenAI embeddings; ARM +12–20% vs FastScan
    - **IVF v2** single-file layout (7–18× smaller than per-cluster files), k-means++ + parallel Lloyd
    - **Rerank** (`keep_raw` build + `rerank_factor` search) — recall@10 0.846 → 0.996 @ ~2 ms
    - **Ensembles** (m permutation-decorrelated indexes, score-averaged) — recall@10 0.888 → 0.939
    - **Filtered search** (`turboquant_search_ivf_filter`) — arbitrary SQL predicate as a `LIST<BIGINT>` allowlist, iterative probe widening
    - **Radius (WITHIN)** search and **incremental** add/remove
    - **Process-wide index cache** — repeated search 37.7 ms → 1.77 ms on 100k vectors
    - **Multiple metrics:** l2, cosine, dot

    **Platforms:** Linux x64, macOS x64/arm64, Windows x64 (WASM and linux_arm64 excluded).

    Built on Google's [TurboQuant](https://github.com/google/turbovec) library.
