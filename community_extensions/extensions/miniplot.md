    Interactive visualization from DuckDB SQL using Plotly.js. Includes bar, line,
    area, scatter, 3D scatter, histogram, box, pie, donut, horizontal bar, violin,
    bubble, heatmap, contour, step, radar, and WebGL scatter charts. Numeric and
    date/time axes preserve numeric spacing and UTC handling for zoned timestamps.

    HTML-returning functions work without file writes or browser launches. Native
    file/browser functions support temporary or explicit output paths and respect
    DuckDB's external-access setting. Plotly.js is loaded from a CDN for ordinary
    HTML viewing; a browser connection or cached bundle is needed.

    Narrative reports accept a documented JSON specification (title and sections
    containing escaped prose plus optional Plotly data/layout/config). Reports
    retain their non-executable JSON specification for agent workflows and
    reproducibility. Function signatures, descriptions and examples are available
    through duckdb_functions().

    Optional chart_export(html, output_path) creates PNG or PDF on a native host.
    This requires a separately installed local Node.js/Playwright/Chromium tool and
    MINIPLOT_EXPORTER pointing to scripts/export-chart.cjs from the source checkout.
    It uses the installed local Plotly bundle without network requests. These tools
    are not bundled in the community extension. Wasm users should use HTML output;
    Wasm cannot spawn the local exporter.

    WebGL scatter supports large point sets without silently sampling data, subject
    to browser/GPU memory limits. Array values must be finite and non-NULL, with
    documented length and grid-shape validation. Measured serialization results,
    report JSON schema, source-build instructions and export setup are in the
    repository README and docs directory.
