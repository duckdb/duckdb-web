  extended_description: |
    Delta Classic lets you attach a directory of Delta Lake tables as a single
    DuckDB database, instead of attaching each table individually. It discovers
    tables by scanning for subdirectories containing a _delta_log folder.

    The extension supports three layouts:
    - Single table: the attached path is itself a Delta table
    - Single-schema: the attached path directly contains Delta tables
    - Multi-schema: the attached path contains subdirectories, each treated as
      a schema, with Delta tables inside them

    All Delta reading is delegated to the Delta extension via internal
    ATTACH ... (TYPE DELTA). The ATTACH options PIN_SNAPSHOT, TIMESTAMP,
    PUSHDOWN_FILTERS and PUSHDOWN_PARTITION_INFO are passed to every table, and
    AT (VERSION => ...) / AT (TIMESTAMP => ...) work per query. Works with all
    storage backends (local filesystem, S3 and S3-compatible stores, ABFSS, GCS).
    Read-only. Not available in DuckDB-WASM, because the Delta extension has no
    WASM build.
