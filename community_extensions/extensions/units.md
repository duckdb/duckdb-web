  extended_description: |
    `units` is a native Rust extension for DuckDB 2.0.0 using C Extension API v2.
    It provides measurement normalization with runtime unit columns, compound-unit
    parsing, dimensional compatibility checks, and distinct conversion functions
    for absolute temperatures and temperature differences. No worker process or
    custom numeric type is required.

    Unit definitions and parsing use the pinned `octofhir-ucum` 0.9.2 backend.
    Syntax follows case-sensitive UCUM 2.2: use `kW.h`, `kg/m3`, `Cel`, and
    `[degF]`. Human spellings are not guessed: `C` is coulomb, not Celsius;
    `MW` and `mW` differ by a factor of one billion.

    Strict conversion raises errors for invalid units and incompatible dimensions.
    Checked conversion returns `STRUCT(value, status, message)`; checked parsing
    returns `STRUCT(definition, status, message)`. Missing inputs have a distinct
    `missing_input` status. This supports auditing and quarantining bad rows before
    normalization. `quantity_parse()` parses a decimal value plus a UCUM unit;
    `quantity_parse_checked()` returns `STRUCT(quantity, status, message)`.
    Quantity text requires a space or tab between the number and unit, rejecting
    ambiguous compact forms, locale-dependent numbers, and out-of-range values.

    `units_catalog()` exposes 312 registered UCUM atoms with definitions and support
    diagnostics; 253 currently pass the extension's conversion policy. Prefixes and
    compound expressions extend beyond this finite catalog. `unit_search()` searches
    codes, names, and properties for discovery, without changing strict parsing.

    Compatibility checks dimensions, not semantic quantity kinds: energy and torque
    are dimensionally compatible. Logarithmic and arbitrary units, affine-temperature
    compounds, quantity algebra, and uncertainty propagation are deliberately outside
    the current scope. SQL results are DOUBLE, not exact rational quantities.

    This is a development version, not yet a production release. Project code is
    licensed under MIT; third-party dependencies and UCUM data retain their
    respective license terms.

    See the [README](https://github.com/sebastiaan-dev/duckdb-units-rs#readme)
    for the full API, numerical limits, and examples, and the
    [roadmap](https://github.com/sebastiaan-dev/duckdb-units-rs/blob/main/docs/ROADMAP.md)
    for release gates.
