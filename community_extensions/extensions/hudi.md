    ## duckdb-hudi

    DuckDB extension that reads [Apache Hudi](https://hudi.apache.org/) tables
    (COW and MOR) using the [hudi-rs](https://crates.io/crates/hudi) Rust kernel.
    Source: https://github.com/alitrack/duckdb-hudi

    ### Install
    ```sql
    INSTALL hudi FROM community;
    LOAD hudi;
    ```

    ### Features
    - Full scan of COW and MOR Hudi tables
    - Time-travel via `as_of` (query a table at a specific instant)
    - Incremental reads (new/changed records since a checkpoint)
    - Table schema + metadata queries
    - Parallel scanning

    ### Build note
    The extension is built from the DuckDB C-API Rust template and its `hudi`
    dependency pulls in the Lance crate, which runs `prost-build` at compile
    time. Building therefore requires `protoc` to be available (this extension
    declares `requires_toolchains: rust`; the protobuf compiler is the one
    toolchain not yet in the default community build environment — see the PR
    description for the resolution).
