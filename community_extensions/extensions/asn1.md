    ## asn1 — ASN.1 BER/CER/DER in SQL

    Decode a DER/BER blob to a nested JSON tree, render it like
    `openssl asn1parse`, resolve OBJECT IDENTIFIERS to names, triage
    well-formedness, pull a node out by path, and re-encode to canonical
    DER — right in DuckDB. No `openssl` on the box, no Python `pyasn1` /
    `asn1crypto`: the parser is pure Rust, compiled in.

    The engine is a port of the MIT-licensed Query-farm ASN.1 codec
    (LICENSE: Copyright Query Farm LLC); the Arrow IPC transport layer was
    replaced with direct DuckDB C-API vector I/O (via
    [quack-rs](https://github.com/tomtom215/quack-rs)). No VGI, no Arrow
    IPC, no JSON shims.

    **8 Functions:**

    | Function | Returns | Notes |
    |----------|---------|-------|
    | `asn1_to_json(payload)` | `VARCHAR` | Nested JSON projection of the TLV tree; malformed blob yields `{"error": ..., "kind": ...}` (never a SQL error) |
    | `asn1_dump(payload, fmt)` | `VARCHAR` | `openssl asn1parse`-style tree; `fmt` in `openssl` (default) / `dumpasn1` (Gutmann-style with OID names) |
    | `asn1_is_valid(payload, rules)` | `BOOLEAN` | Well-formed under `rules` in `der`/`cer`/`ber` (default `der`) |
    | `asn1_well_formed(payload)` | `STRUCT(ok, error, kind)` | BER triage with a classified failure `kind` (`truncated`, `length-overflow`, `invalid-tag`, ...) |
    | `asn1_at_path(payload, path)` | `VARCHAR` | JSON value at a node path, e.g. `asn1_at_path(b, '$.0.2')` |
    | `asn1_oid_name(dotted)` | `VARCHAR` | Dotted OID -> registered name; `NULL` if unknown |
    | `asn1_oid(name)` | `VARCHAR` | Inverse of `asn1_oid_name`; `NULL` if unknown |
    | `asn1_to_der(payload)` | `BLOB` | Re-encode to canonical DER (definite minimal lengths, sorted `SET`); `NULL` if unparseable |

    Useful for cert-trust audits, CRL/OCSP triage, Kerberos ticket
    forensics, and any pipeline that ingests binary protocol captures
    (TLS, PKI, SNMP, LDAP, CMS) into a database.
