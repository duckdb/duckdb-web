  extended_description: |
    The Databricks extension attaches one Unity Catalog catalog as a DuckDB
    database. Tables are read and written with ordinary DuckDB SQL through the
    SQL Statement Execution API. It does not read Delta files, and it does not
    open a Thrift session. Filters, projections, `LIMIT`, and
    `ORDER BY ... LIMIT` can be pushed down to the warehouse.

    Features include:
    - `ATTACH` support for a Databricks catalog, including secrets for a personal access token or a service principal
    - reads from attached schemas and tables
    - writes with `INSERT`, `COPY`, `CREATE TABLE AS`, `UPDATE`, `DELETE`, and `TRUNCATE`
    - `databricks_query` and `databricks_execute` for Databricks SQL that DuckDB cannot express
