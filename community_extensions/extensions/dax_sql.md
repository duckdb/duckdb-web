  extended_description: |
    dax_sql reads a Power BI semantic model, as a TMSL .bim, TMDL files or Apache Ossie YAML
    (a Fabric semantic view's Context/Semantic Views/<view>/ folder), and makes it a semantic view.
    Queries are plain DuckDB SQL: a measure is AGG(name) or AGG("name with spaces"), and a
    dimension is Table.Column. The measures' DAX is compiled to DuckDB SQL at bind time by
    dax-sql (https://github.com/djouallah/dax-sql), embedded in the extension through QuickJS.
    A Direct Lake model's tables are read from its lakehouse through OneLake's Iceberg REST
    catalog, pinned to their snapshots until REFRESH SEMANTIC VIEW. Not built for wasm: OneLake
    is read through the azure extension, which has no wasm build.
