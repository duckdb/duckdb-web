  extended_description: |
    `poached` is a DuckDB extension for SQL parsing and introspection, designed for building IDEs, SQL editors, query analyzers, and developer tools.

    **Tokenization**: `parse_tokens()` (also available as `tokenize_sql()`) returns tokens with byte positions and categories (KEYWORD, IDENTIFIER, OPERATOR, NUMERIC_CONSTANT, STRING_CONSTANT) for syntax highlighting. Comments are stripped before tokenization.

    **Validation**: `is_valid_sql()` and `sql_error_message()` for parse error detection and reporting.

    **Column introspection**: `parse_columns()` returns SELECT column names without executing queries; `parse_column_names()` returns the names as a list.

    **Query analysis**: `parse_tables()`, `parse_functions()`, `parse_where()` to extract structural information from queries.

    **JSON output**: `parse_sql_json()` (also available as `sql_parse_json()`) returns parsed statement types and SQL text, or a parse error.

    For more details, visit the [extension repository](https://github.com/sidequery/poached).
