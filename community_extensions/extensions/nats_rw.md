  extended_description: |
    The nats_rw extension provides bidirectional NATS JetStream access from DuckDB:

    - **Read**: `nats_rw_scan()` table function — bounded snapshot scan with
      subject filtering, sequence/time ranges, JSON field extraction, and
      predicate pushdown (WHERE seq/ts_nats automatically narrows the scan range)
    - **Write**: `COPY … TO '<stream>' (FORMAT nats_rw)` — publish query results
      with optional payload_column, subject_prefix, and auto stream creation
    - **Auth**: `CREATE SECRET (TYPE nats_rw, …)` — user/password, token, nkey,
      or credentials file, with scope-based auto-matching
    - **Metadata**: `nats_rw_streams()` and `nats_rw_stream_info()` for inspection
    - **Performance**: connection pooling (per-url cache) + predicate pushdown

    Connections are cached per (url, auth) for efficient repeated queries.

    Documentation: https://github.com/robert-guangzhou/duckdb-nats-rw
