  extended_description: |
    The `oracle` extension connects DuckDB directly to Oracle databases for reading and writing tables, views, materialized views, and synonyms.

    Installing and loading the extension requires no Oracle libraries on the host. When opening a connection, the extension loads Oracle Instant Client (19c, 21c, or 23ai) on demand from `OCI_LIB_DIR`, `ORACLE_HOME`, or the system library path. It works with local, on-premises, cloud, and Oracle Autonomous Database instances, including connections authenticated with Oracle Wallets.

    Key features:
    - **Catalog attachment & direct SQL**: Attach an Oracle database via `ATTACH ... (TYPE oracle)` to query tables directly, or run raw SQL with `oracle_query` and `oracle_execute`.
    - **Optimizer pushdown**: Pushes `WHERE` filters, column projections, table row-count estimates, and flashback queries (`AS OF SCN` and `AS OF TIMESTAMP`) down to Oracle.
    - **Rich type mapping**: Maps Oracle numeric, temporal, `CLOB`/`BLOB`, `RAW`, `JSON`, 23ai `VECTOR` embeddings (`LIST(FLOAT)`), and `SDO_GEOMETRY` spatial geometries (`GEOMETRY`).
    - **Batched reads & writes**: Uses array fetching for scans and array binding for `INSERT INTO` writes.
