  extended_description: |
    `decide` asks decision models yes/no, multiple-choice, and rubric questions
    from SQL. It supports OpenAI Decisions (the default, `gpt-6-luna`),
    TypeSafe Jev, and Cloudflare Clef (Workers AI) with the same functions:
    boolean predicates, probabilities, categorical choices, rubric scores, and
    explicit multi-question JSON answers. `SELECT * FROM decision_providers()`
    lists the providers, models, and credential names.
    Typed functions batch 20 rows per request by default; set
    `decisions_batch_size = 1` for independent row evaluation.
    Non-NULL inputs and instructions are sent to the selected provider and can
    incur API charges.

    ### Credentials

    Keep one `decisions` secret per provider, scoped to it, so each key is sent
    only to its own provider. Each provider also reads an environment variable.

    ```sql
    CREATE OR REPLACE SECRET openai_key (TYPE decisions, API_KEY 'sk-...', SCOPE 'decisions://openai');
    CREATE OR REPLACE SECRET jev_key (TYPE decisions, API_KEY 'your-typesafe-key', SCOPE 'decisions://jev');
    CREATE OR REPLACE SECRET cf_key (TYPE decisions, API_KEY 'workers-ai-token',
                          ACCOUNT_ID 'your-account-id', SCOPE 'decisions://cloudflare');
    ```

    The environment variables are `OPENAI_API_KEY`, `TYPESAFE_API_KEY`, and
    `CLOUDFLARE_API_TOKEN` with `CLOUDFLARE_ACCOUNT_ID`.

    ### TypeSafe Jev and Cloudflare Clef

    ```sql
    SET decisions_provider = 'jev';        -- default model jev-latest
    SET decisions_provider = 'cloudflare'; -- default model clef; also 'clef-flash'
    SET decisions_model = 'jev-1.14.0';    -- optional override; RESET when switching
    SELECT decision_prob('The parcel arrived crushed.',
                         'Does this report physical damage?') AS probability;
    ```

    Clef caps requests at 64 questions. Neither Jev nor Clef returns refusal
    answers. All providers accept text only.

    No API key is required to build or run the offline tests.
    This is an independent integration, not an official extension of OpenAI,
    TypeSafe, or Cloudflare.
    See the [README](https://github.com/gzheng92/duckdb-decide#readme)
    for function signatures, limits, refusal handling, and batching semantics.
