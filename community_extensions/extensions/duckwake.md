  extended_description: |
    DuckWake keeps a SQL view's table in a DuckLake lake current as events arrive from Kafka. Each epoch (every
    10 seconds by default) commits the view's new rows, its state and the Kafka offsets in one DuckLake
    transaction, so a crash never loses or repeats an event, and `duckwake_verify` checks a view against its
    query run as one batch. Views can filter, join lake tables, aggregate over tumbling and hopping windows or
    per group, and read other views and lake tables through their change feed.

    The extension runs a worker inside the DuckDB process (`duckwake_worker_start`); the same engine also runs
    as the `duckwaked` server and the `duckwake` CLI. It needs a DuckLake catalog in PostgreSQL and Kafka
    (JSON messages). Documentation: https://duckwake.github.io
