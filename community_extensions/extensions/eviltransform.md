    Port of [pg_eviltransform](https://github.com/aiyou178/pg_eviltransform) to DuckDB.
    Adds WGS84 / GCJ02 / BD09 transformations for points, lines, polygons,
    multi-geometries and nested collections. Z/M ordinates are preserved by the
    custom coordinate formulas. Standard projections, including geographic
    CGCS2000 (EPSG:4490), delegate to the spatial extension.

    Install and load `spatial` before loading `eviltransform`. The explicit
    three-argument interface is `ST_EvilTransform(geometry, from_crs, to_crs)`;
    coordinates use longitude/easting as X and latitude/northing as Y.
    Custom CRS metadata is not attached to the output. The original approximate
    GCJ02 inverse and rectangular China guard are retained.

    `ST_JenksBins(values, breaks[, invert])` computes exact weighted Jenks
    natural breaks from a list. `ST_JenksBinsAgg(value, breaks[, invert])` is
    the streaming aggregate and supports parallel combine.

    Uses the stable C extension ABI v1.2.0. Loading creates/replaces the
    `ST_EvilTransform` macro in the database's main schema, so initialization
    requires a writable database. WebAssembly is excluded from this release.
    See the [README](https://github.com/aiyou178/duck_eviltransform#readme) for
    aliases, NULL handling, accuracy and installation details.
