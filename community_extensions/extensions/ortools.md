    Solve optimization models directly in DuckDB SQL using native C++ OR-Tools.
    No API key, hosted solver, or Python solver runtime is required.

    `ortools_solve` accepts a versioned JSON model and returns a typed solution
    struct containing status, objective, bound, decision values, timing, and
    infeasibility diagnostics. CP-SAT handles integer and Boolean constraints;
    GLOP handles continuous linear optimization. `ortools_allocate` supports
    relational allocation with capacity and demand shared across input chunks.
    Active searches honor DuckDB query cancellation.

    The community build is self-contained: its pinned, minimal OR-Tools
    dependencies are statically linked. Gurobi, CPLEX, Xpress, COIN-OR, GLPK,
    SCIP, HiGHS, and PDLP are disabled. License and modification notices are
    embedded and readable with `SELECT ortools_licenses();`.
