  extended_description: |
    dmb applies a DCS sheet to a duck_blocks document and returns a new document. A selector
    chooses blocks, as in CSS. The declarations set ids and attributes, drop sections, wrap or
    retype blocks, add generated text, reorder blocks, and write front matter. Any duck_block_utils
    renderer can then write the result as Markdown, HTML or text.

    Functions: `dcs_apply`, `dcs_select`, `dcs_explain`, `dcs_check`, `dcs_rules`,
