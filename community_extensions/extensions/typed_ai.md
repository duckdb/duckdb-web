  extended_description: |
    `typed_ai` lets you ask an AI simple questions about each row of a table, straight from SQL. It is built
    for [TypeSafe Jev](https://docs.typesafe.ai), which in our tests (October 2026) gave the most accurate answers at
    the lowest cost, since it answers many rows in one request. It also works with OpenAI, or with a free local AI on
    your own computer through Ollama. New AI services work too, with no update needed, as long as they use
    OpenAI's format and report how sure they are: point a secret at their web address.

    | Function | What you get back |
    | --- | --- |
    | `typed_is(value, statement [, cutoff])` | true or false, for filtering with `WHERE` |
    | `typed_prob(value, statement)` | how likely the statement is true, from 0 to 1 |
    | `typed_pick(value, question, options)` | the best option; the options can come from a table |
    | `typed_score(value, question, levels)` | a rating on your scale, e.g. 0 for the lowest level up to 3 |
    | `typed_ask(value, question_json)` | the full answer, with the odds for every option |
    | `typed_usage()` | what you have spent, your limit, and how many answers were reused for free |

    `value` can be text, any other value, or a whole row.

    Safe by default:

    - At most 1,000 rows per query and $1.00 in total, until you raise `typed_max_rows` or `typed_budget_usd`.
    - `SET typed_dry_run = true` shows what a query would cost without asking the AI anything.
    - If a job stops partway, the answers you paid for are kept. Run it again and you pay only for the rest.

    Each value you check is sent to the AI service you set up. For private data, use a local model, so nothing
    leaves your computer.

    #### Audit an AI agent

    Did the agent do more than it was asked? The whole row goes in, so the model compares the request with the action.

    ```sql
    CREATE TABLE agent_log AS FROM (VALUES
      ('book a table for 2 on Friday', 'booked a table for 2, Friday 7pm'),
      ('cancel my gym membership', 'cancelled it and deleted all workout history'),
      ('find a cheaper phone plan', 'listed 3 cheaper plans'),
      ('reply to Sam that I am running late', 'replied to Sam and to everyone in the team chat'),
      ('pay the electricity bill', 'paid the bill and set up autopay for 12 months'))
      t(asked, did);

    SELECT asked, typed_prob(a, 'the agent did more than the user asked for') AS overreach
    FROM agent_log a ORDER BY overreach DESC;
    -- reply to Sam that I am running late   0.95
    -- pay the electricity bill              0.95
    -- cancel my gym membership              0.93
    -- book a table for 2 on Friday          0.60   (the agent chose 7pm on its own)
    -- find a cheaper phone plan             0.19
    ```

    #### Find private data before sharing

    Jev and a local model both name the kind of private data. To keep the notes on your machine, run
    `SET typed_profile = 'local'` first; the yes/no odds are less reliable on a small local model.

    ```sql
    CREATE TABLE notes AS FROM (VALUES
      (1, 'Customer liked the new blue colour, wants it in size 10.'),
      (2, 'Call Priya back on 07700 900123 after 5pm.'),
      (3, 'Said she is on chemo, so deliveries must be left at the door.'),
      (4, 'Paid with a card ending 4417, asked for a refund next month.'),
      (5, 'Asked if the store opens on bank holidays.')) t(id, note);

    SELECT id, typed_pick(note, 'what private data does this note contain?',
      ['none', 'contact details', 'health', 'money']) AS found FROM notes;
    -- 1 none   2 contact details   3 health   4 money   5 none
    ```
