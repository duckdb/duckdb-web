  extended_description: |
    `read_prs(path)` is a table function that reads SAS (`.sas7bdat`), Stata (`.dta`) and SPSS
    (`.sav`, `.zsav`) files, and the less common SAS transport (`.xpt`) and SPSS portable (`.por`)
    formats. The format is taken from the file extension.

    ```sql
    SELECT age, income FROM read_prs('survey.sav') WHERE age >= 18;
    CREATE TABLE survey AS SELECT * FROM read_prs('survey.sas7bdat');
    ```

    - Only the columns a query uses are read from the file.
    - Files are opened through DuckDB's file system, so `s3://` paths use your DuckDB secrets and
      settings.
    - Options follow polars_readstat: `preserve_order`, `row_index_name`,
      `value_labels_as_strings`, `missing_string_as_null`, `row_offset`, `n_rows`, `threads` and
      `batch_size`.
    - `COPY ... TO` writes any query result as Stata (`FORMAT dta`), SPSS (`FORMAT sav`), a CSV
      plus a SAS script that loads it (`FORMAT sas_csv`), SAS transport (`FORMAT xpt`) or SPSS
      portable (`FORMAT por`), with variable labels.

    It reads files with the same Rust core as [polars_readstat](https://github.com/jrothbaum/polars_readstat).
    Documentation: https://github.com/jrothbaum/duckdb_prs
