## Installing via Pip

The latest release of the Python client can be installed using `pip`.

```batch
pip install duckdb
```

The pre-release Python client (known as the “preview” or “nightly” build) can be installed using `--pre`.

```batch
pip install duckdb --upgrade --pre
```
