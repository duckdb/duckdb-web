> The `sirius` extension is not yet available. It is coming soon.

The `sirius` extension adds GPU-accelerated query execution to DuckDB. [Sirius](https://www.sirius-db.com/) is a GPU-native SQL engine that runs DuckDB queries on NVIDIA GPUs.
