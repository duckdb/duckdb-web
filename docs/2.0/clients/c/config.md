<!-- markdownlint-disable MD001 -->

Configuration options can be provided to change different settings of the database system. Note that many of these
settings can be changed later on using [`PRAGMA` statements](../../configuration/pragmas) as well. The configuration object
should be created, filled with values, and passed to `duckdb_open_ext`.

## Example

```c
duckdb_database db;
duckdb_config config;

// create the configuration object
if (duckdb_create_config(&config) == DuckDBError) {
    // handle error
}
// set some configuration options
duckdb_set_config(config, "access_mode", "READ_WRITE"); // or READ_ONLY
duckdb_set_config(config, "threads", "8");
duckdb_set_config(config, "max_memory", "8GB");
duckdb_set_config(config, "default_order", "DESC");

// open the database using the configuration
if (duckdb_open_ext(NULL, &db, config, NULL) == DuckDBError) {
    // handle error
}
// cleanup the configuration object
duckdb_destroy_config(&config);

// run queries...

// cleanup
duckdb_close(&db);
```

#### `duckdb_create_config_option`

Stable since 1.5.6.

Creates a configuration option instance.

##### Syntax

```c
duckdb_config_option duckdb_create_config_option(void);
```

##### Return Value

The resulting configuration option instance. Must be destroyed with `duckdb_destroy_config_option`.

<br>

#### `duckdb_destroy_config_option`

Stable since 1.5.6.

Destroys the given configuration option instance.

##### Syntax

```c
void duckdb_destroy_config_option(
  duckdb_config_option *option
);
```

##### Parameters

* `option`: The configuration option instance to destroy.

<br>

#### `duckdb_client_context_get_config_option`

Stable since 1.5.6.

Retrieves the value of a configuration option by name from the given client context.

##### Syntax

```c
duckdb_value duckdb_client_context_get_config_option(
  duckdb_client_context context,
  const char *name,
  duckdb_config_option_scope *out_scope
);
```

##### Parameters

* `context`: The client context.
* `name`: The name of the configuration option to retrieve.
* `out_scope`: Output parameter to optionally store the scope that the configuration option was retrieved from.
If this is `nullptr`, the scope is not returned.
If the requested option does not exist the scope is set to `DUCKDB_CONFIG_OPTION_SCOPE_INVALID`. (out)

##### Return Value

The value of the configuration option. Returns `nullptr` if the option does not exist.

<br>

#### `duckdb_profiling_info_get_value`

Stable since 1.1.0.

Returns the value of the metric of the current profiling info node. Returns nullptr, if the metric does
 not exist or is not enabled. Currently, the value holds a string, and you can retrieve the string
 by calling the corresponding function: char *duckdb_get_varchar(duckdb_value value).

##### Syntax

```c
duckdb_value duckdb_profiling_info_get_value(
  duckdb_profiling_info info,
  const char *key
);
```

##### Parameters

* `info`: A profiling information object.
* `key`: The name of the requested metric.

##### Return Value

The value of the metric. Must be freed with `duckdb_destroy_value`

<br>
