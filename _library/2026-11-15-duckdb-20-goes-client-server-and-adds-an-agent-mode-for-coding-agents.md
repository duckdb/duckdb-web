## Description

In this episode of The New Stack Podcast, Gábor Szárnyas, developer advocate at DuckLabs, discusses DuckDB 2.0, the biggest feature release of DuckDB to date. Gábor walks through the new server capabilities, the extensible SQL parser, the Quack remote protocol, and Agent Mode, which gives AI coding agents compact Markdown tables and machine-readable errors to help them fix their SQL queries with fewer tokens. The conversation also covers the storage compatibility changes behind the major version bump, why production migrations should be done with care, the upcoming DuckDB 2.0.1 bugfix release, and DuckDB's role within AWS.
