An article announcing that Amazon Aurora PostgreSQL can directly query Apache Iceberg and Parquet data in a data lake. DuckDB is embedded within Aurora PostgreSQL and handles the analytical scans of the data lake files, allowing users to combine live operational data with Iceberg data in a single query.
