## Description

In this episode of The New Stack Podcast, Guillermo Sanchez, product lead at DuckLabs, discusses Quack 1.0, DuckDB's HTTP-based client-server protocol. Guillermo explains how traditional row-based database protocols introduce overhead and inefficient serialization, and how Quack instead builds on DuckDB's columnar data representation and vectorized execution engine. The conversation covers Quack's streaming architecture, which lets clients consume results as they are generated, as well as simplified remote connections, command-line server deployment, and improved transaction throughput and concurrency.
