## Description

In this episode of The New Stack Podcast, Pedro Holanda, lead DuckLake developer, discusses DuckLake, the open lakehouse format that stores table metadata in a SQL database instead of manifest files on object storage. Pedro explains how this lets a single query find exactly which Parquet files to read, and walks through the DuckLake 1.1 release, which adds maintenance features such as file consolidation and data inlining to tackle the small files problem in streaming workloads.
