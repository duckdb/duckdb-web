DuckDB

The in-process analytical SQL database. Simple by default, fast and reliable by design — built to work anywhere and embed easily. It is the foundation the other two build on.

Explore DuckDB

Quack

The client-server protocol for DuckDB. Query a remote DuckDB instance with the same SQL and the same clients — no new database to learn, no drivers to swap.

Explore Quack

DuckLake

The lakehouse format built on DuckDB. Your data lives in open Parquet files, the catalog in SQL — transactional, portable and free of lock-in.

Explore DuckLake

Iceberg

First-class Apache Iceberg support. Read and write Iceberg tables directly from DuckDB — no extra infrastructure required.

Explore Iceberg
